A State Of Mind
Phase 1 of 4

Technical SEO

Technical SEO Audit

  • Conduct a comprehensive technical SEO audit to identify crawling, indexation, and website structure issues.
  • Review URL consistency, duplicate pages, broken links, redirect chains, and orphan pages.
  • Check mobile usability, HTTPS security, and other technical factors affecting search visibility.
  • Prioritize issues based on their impact on crawling, indexing, performance, and user experience.

SEO Tools & Rank Tracking Setup

  • Set up the project in a Rank Tracking tool.
  • Configure the website and target location.
  • Add target keywords and record baseline rankings.
  • Configure competitor tracking where applicable.
A State Of Mind
Phase 1 of 4

Technical SEO

Shopify SEO Plugin Optimization

  • Install Yoast SEO for Shopify and configure global settings, including title and meta description templates.
  • Optimize metadata for the homepage, products, collections, pages, and blog posts.
  • Configure indexing rules for pages, collections, and blog posts.
  • Validate Yoast settings and structured data across important store pages, avoiding overlap with the theme's schema.

XML Sitemap & Robots.txt Optimization

  • Review and optimize the XML sitemap and robots.txt directives.
  • Ensure important, indexable pages are included in the sitemap and accessible to search engines.
  • Exclude inappropriate or non-indexable URLs from the sitemap where necessary.
  • Submit the sitemap to Google Search Console and verify its processing status.
A State Of Mind
Phase 1 of 4

Technical SEO

Website Performance & Core Web Vitals

  • Analyze website speed and Core Web Vitals.
  • Identify performance issues related to images, scripts, CSS, and page loading.
  • Recommend and implement improvements where possible.
  • Validate performance after optimization.

Technical Fixes & Quality Assurance

  • Implement prioritized technical fixes identified during the audit.
  • Validate crawling, indexation, redirects, canonical tags, and internal links after implementation.
  • Recheck mobile usability, HTTPS functionality, and technical errors.
  • Document completed fixes and outstanding issues.
